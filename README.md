# analisedeDeliverydeRefei-es

## Análise dos pedidos

O notebook [`analise_pedidos_delivery.ipynb`](./analise_pedidos_delivery.ipynb) realiza a análise exploratória dos arquivos `pedidos.csv` e `cardapio.csv`, trata valores ausentes, calcula receita por item, apresenta agregações por item e categoria, acompanha a receita mensal e calcula KPIs e percentis.

Para executar, abra o notebook com Jupyter ou VS Code e rode as células em ordem a partir da raiz do projeto. O ambiente precisa ter `pandas`, `numpy` e `matplotlib` instalados.
